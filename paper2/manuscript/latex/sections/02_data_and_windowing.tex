\section{Data and Windowing}

\subsection{Data set}

We analyze consecutive prime gaps in the interval
\[
[10^{10},\,3\times 10^{10}).
\]
Let $p_n$ denote the $n$-th prime. The data set contains
\[
n = 844{,}953{,}415
\]
consecutive prime gaps
\[
g_n = p_{n+1}-p_n.
\]
The center of the interval in log scale is
\[
\log p_{\text{center}} = 23.575157.
\]
The raw gap variance is
\[
\operatorname{Var}(e) = 438.670412,
\]
with standard deviation
\[
\operatorname{sd}(e) = 20.944.
\]
The lag-one covariance is
\[
\operatorname{Cov} = -11.001171,
\]
and the raw lag-one correlation is
\[
\rho_1 = -0.025078.
\]
These values reproduce the frozen predictions made before the $10^{10}$ run.

\subsection{Local detrending}

We follow the windowed local detrending procedure frozen in the analysis protocol and used in Berramdane (2026a). The detrending removes the local scale trend within each window so that the remaining signal reflects serial dependence rather than slow variation in gap size. No parameter of the detrending is changed in the present study. The residual gaps are the input to the covariance and correlation analyses reported below.

The variance and covariance values reported below are those of the detrended residual $e_n$, not of the raw gap $g_n$. The relation is $\operatorname{Var}(e) = \operatorname{Var}(g) - \beta^2 \operatorname{Var}(\log p)$, with $\beta \approx 1$ in the present window.

\subsection{Phase conditioning}

For each primorial modulus
\[
M \in \{6,\,30,\,210,\,2310,\,30030,\,510510,\,9699690\},
\]
we condition on the opening-prime residue
\[
r = p_n \bmod M.
\]
This partitions the gaps into $\varphi(M)$ phase classes. Table~\ref{tab:class-sizes} lists, for each $M$, the average number of gaps per class $n_c$ and the minimum class count $\min\_class$.

\subsection{Windowing and resampling}

The $10^{10}$ data set is divided into 40 contiguous blocks for the block bootstrap. Confidence intervals for $\rho_{\text{resid}}$ are obtained by resampling these blocks. The bootstrap uses independent seeds for each $M$ and is described in the frozen protocol. The resulting $95\%$ intervals are reported in Section~4.5.

\subsection{Reproducibility}

All results in this paper are computed from the frozen $10^{10}$ data set. No value is reported without a corresponding run. The file \texttt{phase\_decomposition\_v2.csv} contains the full table of $M$, the covariance decomposition, the variance split, and the bootstrap intervals.
