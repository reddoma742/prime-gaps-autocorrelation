# prime-gaps-autocorrelation

Code, data and LaTeX sources for

> **Persistent Negative Lag-One Dependence in Locally Detrended Prime-Gap
> Windows up to N = 10^9, with Absence of Significant Positive
> Autocorrelation up to K = 1024**

**Author.** BERRAMDANE Reddouane — independent researcher.
**Contact.** `reddoma@gmail.com`

---

## What the paper claims

The gap sequence `g_n = p_{n+1} - p_n` of consecutive primes is analysed
with an exact segmented sieve up to `N = 10^9`, which yields **50,847,532
even gaps** (the initial odd gap `g_1 = 3 - 2 = 1` is excluded).

| Result | Value |
|---|---|
| Lag-one autocorrelation `ρ₁` | negative in **all ten** logarithmic windows spanning `[10^4, 10^9)` |
| Magnitude | `ρ₁ ≈ -0.095` in the smallest window, `ρ₁ ≈ -0.031` in the largest |
| Significance | moving-block bootstrap 95% CI excludes zero in every window |
| Decay law | `\|ρ₁\| ~ (log p)^{-c}`, weighted 8-window fit `c = 1.28 ± 0.05`, bootstrap CI `[1.14, 1.57]` |
| Sensitivity | `c ∈ [1.26, 1.57]` across window-set choices |
| `c = 2` (quadratic) | excluded at `3.7σ` to `14.4σ`, and at `6.6σ` on the bootstrap scale |
| `c = 1` (logarithmic) | excluded at `2.6σ` to `5.6σ` across window sets; only `≈2.5σ` on the bootstrap scale, so **suggestive rather than decisive** |
| Lags up to `K = 1024` | no significant positive autocorrelation at any individual lag: 255 of 1024 lags positive (24.9%), largest `+3.86×10⁻⁴` against a Bonferroni threshold of `5.70×10⁻⁴` |
| Raw (non-detrended) global correlogram | 1016 of 1024 positive lags, maximum `+4.24×10⁻³`, exceeding the threshold by a factor of 7.45 — **a non-stationarity artifact that disappears entirely upon detrending** |
| Lemke–Oliver–Soundararajan, mod 3 | stay probability `0.44509` and `0.44514`, deviating from `1/2` by `≈ -0.055` at `z ≈ -553σ`; the suppression is the same in both residue classes (`z = 0.33`) |
| Pair ratios | inclusion–exclusion model reproduces observations to `0.37%` mean absolute error, a `9.6×` improvement over the naive Hardy–Littlewood heuristic, with no fitted constants |
| Byproduct | the telescoping identity for `δ_n = g_n - log p_n` yields `ψ(10^9) - 10^9 = +1,595.99`, consistent with the explicit bounds of Büthe |

Not claimed: a proof of any asymptotic law; a universal bound on `ρ₁`;
a quantitative test of the conjectured per-class constants of the
Lemke–Oliver–Soundararajan conjecture, which is left open.

The headline estimate of `c` is **sensitive to the choice of window set**
and that sensitivity is reported rather than suppressed. See
Limitations and Reproducibility in the manuscript.

## Reproducing

**Requirements.** A C++17 compiler (`g++`), `bash`, a LaTeX installation
with `pdflatex` and `bibtex`, and Python 3.9+ with the packages in
`requirements.txt` (`numpy`, `pandas`, `matplotlib`, `scipy`).

```bash
./build_all.sh
```

The five stages are: compile the three C++ binaries, run them (≈22 h on a
single four-thread workstation with no GPU — uncomment stage 2 only if you
need to regenerate `data/`), run the Python analysis, assemble the LaTeX
package, compile the PDF.

To rebuild the PDF from the sources already in `data/` without the 22-hour
stage, run stage 3 onward:

```bash
cd src/python
python fit_c.py
python delta_mean_verify.py
python compute_psi.py     # ~20 s, numpy only
python make_figures.py
python make_appendix_b.py
cd ../.. && ./build_all.sh
```

`compute_psi.py` needs only `numpy`. It re-derives Appendix A by direct
enumeration of the primes below `10^9` and checks itself against
`π(10^k)` for `k = 4 … 9`. Expected values (formatting abbreviated):

```
pi(10^9)                    = 50847534      OK
theta(P)  math.fsum path     = 999968978.577566147
theta(P)  np.sum path        = 999968978.577566147
difference                   = 0.000e+00
P - theta(P)                 = 30958.422434
psi(10^9) - 10^9 direct      = 1595.990428
psi(10^9) - 10^9 via delta_bar= 1595.990818
difference                   = -3.908e-04
```

The last three lines are the cross-check: the value inferred from the gap
sequence and the value obtained by enumerating the primes agree to
`3.9×10⁻⁴`, which is about one sixth of the `±0.0025` that the
seven-significant-digit rounding of the pipeline's own `δ̄` permits.

## Erratum on the published PDF

The preprint deposited on Zenodo on 2 October 2026
([10.5281/zenodo.23111512](https://doi.org/10.5281/zenodo.23111512)) carries a
bibliography with two errors, found on 3 October 2026 by checking all 23
entries of `paper/refs.bib` against Crossref, OpenAlex, zbMATH and the
publishers' own APIs:

- **Brent** was dated 1973. The volume, the issue number and the pages were
  correct; only the year was wrong. The correct record is *Mathematics of
  Computation* **28**(125), 315-324, **1974**,
  [10.1090/S0025-5718-1974-0330017-X](https://doi.org/10.1090/S0025-5718-1974-0330017-X).
  The `0330017` in that DOI is the AMS submission number, and it encodes 1974.
- **Bartlett 1946** had a garbled, non-existent title. The correct one is *On
  the theoretical specification and sampling properties of autocorrelated
  time-series*, JRSS-B **8**(1), 27-41,
  [10.2307/2983611](https://doi.org/10.2307/2983611).

Three further defects were corrected at the same time: the URL of Oliveira e
Silva's tables of $\pi(x)$ had gone dead (`http://www.ieeta.pt/~tos/primes.html`
now returns 404; the tables live at `https://sweet.ua.pt/tos/primes.html`, which
is the address OEIS itself cites); the OEIS entry used `$\le 10^n$` instead of
the official sequence name *Number of primes < 10^n*; and four titles were
losing their capital letters to the BibTeX style (`Cramér`, `Partitio
Numerorum`, `A006880`, `The On-Line Encyclopedia of Integer Sequences`).

The manuscript body is untouched by this erratum. Not one sentence, number or
table changed: `manuscript.tex` differs from the deposited version only by the
two `\cite{Brent1973}` keys, and the document still compiles to 21 pages with no
error and no undefined reference.

**The correction is not in the deposited PDF.** A Zenodo preprint record has
frozen files, and that PDF was produced on Overleaf, so it cannot be patched
locally. A version 2 is therefore required, under the same concept DOI
`10.5281/zenodo.23111511`. It has not been uploaded: this is a public and
irreversible act, so it waits for an explicit decision, and it needs a PDF
recompiled on Overleaf from these corrected sources first.

A byte-exact copy of the deposited PDF was kept before any change, along with
its MD5, which still matches the one Zenodo publishes:
`f7b390a57bdd75a114811e04b8213062`.
